## What is DOLM-backbone

DOLM-backbone provides a structured learning path to get you started with our DOLM through a secure, API-based interface.
It is designed to enable developers and organizations to integrate DOLM capabilities into their applications without managing model infrastructure or training pipelines.


## Launch the DOLM-backbone locally
To launch the documentation locally, simply run the following command at the root of the repository:
```sh
python -m mkdocs serve
```
