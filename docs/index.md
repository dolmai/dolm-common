# Introduction
## What is DOLM

DOLM - DevOps Oriented Language Model, is built on top of a decoder-only Transformer architecture. It is designed for autoregressive text generation.
With approximately 100 million parameters, DOLM balances computational efficiency and expressive power, capturing both short-term and long-term dependencies in language

DOLM is trained on a large dataset of DevOps-oriented language, including scripts, command-line examples, and documentation. 
This specialized training makes DOLM particularly effective at understanding and generating text in the DevOps domain, such as infrastructure automation scripts, deployment pipelines, or system configuration instructions. Its domain expertise allows it to provide accurate, contextually relevant, and technically precise outputs for DevOps tasks.
